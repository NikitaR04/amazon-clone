# Amazon Clone

A responsive Amazon Clone website built using HTML5 and CSS3.  
This project recreates the frontend design and layout of Amazon, including navigation bar, product sections, banners, and footer components.

## Features
- Responsive homepage layout
- Amazon-style navigation bar
- Product category sections
- Banner and promotional sections
- Footer section design
- Mobile-friendly UI

## Technologies Used
- HTML5
- CSS3

## Learning Outcomes
- Improved frontend development skills
- Practiced responsive web design
- Worked with semantic HTML structure
- Enhanced UI and layout designing skills
